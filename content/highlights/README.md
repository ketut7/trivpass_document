# Trivpass Instagram Highlights

Evergreen Story Highlights for the profile. Built from Stories (post a slide as a Story → add to the highlight). Slides are **9:16 (1080×1920)**, distinct from the 4:5 feed.

## Production flow

1. Enable **Save to Archive** (Settings → Story) so slides can be added to highlights anytime.
2. Post the highlight's slides as **Stories in order** (order in a highlight = order posted, oldest → newest).
3. Add them to the highlight.
4. Set the **cover**: Edit Highlight → Edit Cover → upload the icon image (it does not need to be a Story).
5. Add a **link sticker** to the CTA slide in-app (→ trivpass.com).

Cover spec: 1080×1920 image, off-white (#faf7f2) field, **one** jungle-green (#1f4d3a) outline icon centered, generous margin (only the center circle shows). Monochrome — no terracotta, no photo, no text in the cover. The label under the circle is rendered by Instagram, not by you — keep titles short.

## Shared 9:16 prompt skeletons

Plug each slide's `EYEBROW / TITLE / BODY` (and `PHOTO`) into the right skeleton.

**Skeleton A — text-led (T3)**
```
Create a 9:16 Instagram Story slide (portrait, 1080x1920). Trivpass brand.
A clean branded text card on warm off-white (#faf7f2) — NO photo.
- TOP: Trivpass logo (small jungle-green ticket/leaf mark + lowercase serif "trivpass" #1f4d3a + terracotta dot), ABOVE the title. Generous story-safe top/bottom margins.
- Eyebrow, uppercase terracotta (#c2603e): <EYEBROW>
- Title, elegant warm serif, jungle-green (#1f4d3a): <TITLE>
- Body, clean sans-serif, dark gray: <BODY>
STYLE: calm editorial, generous negative space. NO faces, NO neon, NO electric blue, NO magenta, NO gradient, NO drop shadow, NO decorative graphics or fake UI, NO IG stickers/GIFs. Text flat, no outline/shadow.
```

**Skeleton B — photo (T1)**
```
Create a 9:16 Instagram Story slide (portrait, 1080x1920). Trivpass brand.
LAYOUT: warm off-white (#faf7f2) upper area, documentary photo filling the lower ~55%.
- TOP: Trivpass logo (as above), ABOVE the title. Story-safe margins.
- Eyebrow, uppercase terracotta (#c2603e): <EYEBROW>
- Title, elegant warm serif, jungle-green (#1f4d3a): <TITLE>
- Body, clean sans-serif, dark gray: <BODY>
PHOTO: <PHOTO>. No faces — backs / silhouettes / hands / objects only.
STYLE: photorealistic documentary, warm & slightly desaturated — NOT glossy/HDR/oversaturated. NO neon, electric blue, magenta, gradient, drop shadow, decorative graphics, fake UI, IG stickers. Text flat.
```
