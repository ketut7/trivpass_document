## Image Prompt Specs (AI-generated visuals)

AI-generated images are approved for social content while real Trivpass photography is unavailable. Every image prompt must hold the brand look and the slide layout below.

### Format

- Generate the final asset directly as 4:5 Instagram portrait (1080x1350). Do not rely on placing a taller raw image onto a 1080x1350 canvas afterward.
- Prefer generating clean photographic backgrounds + adding text in Canva (Fraunces headlines, Inter body). One-shot prompts with embedded text are acceptable but AI text is imperfect — always verify the "trivpass" wordmark spelling and tidy in Canva.

### Brand STYLE block (paste into every image prompt)

```
STYLE (Trivpass brand, strict):
- Photorealistic documentary travel photography. NOT illustration, NOT 3D, NOT stylized.
- Warm, daylight, slightly desaturated, warm-shifted grade — like late-afternoon light through a window. NOT glossy, NOT HDR, NOT oversaturated, NOT Instagram-beach-edit.
- Calm, deliberate, unglamorous, confident. Generous clean negative space.
- Real Bali location; real-feeling people, candid, no stock-grade posed smiles.
- Warm off-white tones (#faf7f2). NO electric blue, NO neon, NO magenta/pink, NO gradient overlay, NO drop shadow, NO decorative graphics (no boarding pass, polaroid frames, fake UI cards, cartoon map icons).
- Aspect: final 4:5 Instagram portrait (1080x1350). Compose the layout for this exact ratio from the start.
- Text rendered flat: no outline, no shadow.
```

### Slide layout convention (locked)

Every carousel slide uses this stack, top to bottom:

1. **Logo at the very top, ABOVE the title** — small jungle-green ticket/leaf mark beside the lowercase serif wordmark `trivpass` (#1f4d3a) with a small terracotta dot. Top-left.
2. **Eyebrow** — uppercase, terracotta (#c2603e). Optional on pure-CTA slides.
3. **Title** — elegant warm serif (Fraunces), jungle-green (#1f4d3a).
4. **Body** — clean sans-serif (Inter), dark gray. Interior slides only.
5. **Photo** — documentary photo filling the lower ~50-55% of the slide. The cover can run the photo larger.

Keep the upper text area on warm off-white (#faf7f2) for legibility. Same stack on every slide so the set reads as one system.

### CTA in images

- CTA wording: **"Secure Your Driver & Tickets"** (never "Book Now"). Sanctioned variants: "Reserve Your Spot" (capacity-limited cultural events), "View driver profile" (trust posts).
- Button = rounded-rectangle (8px corners, NOT a pill), solid jungle-green fill (#1f4d3a), off-white text (#faf7f2).
- Terracotta is signal only (eyebrow, price, scarcity) — never a CTA fill.
- Cultural Events / awareness posts use a soft CTA (save / send a message), no hard-sell button.

## Caption Formula

Start with one clear hook.

Then add 2-4 short sentences with concrete detail.

End with one CTA.

Use 6-10 hashtags. Prefer:
